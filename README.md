# Wilkinson-power-divider---design-and-simulation
It is an equal-split Wilkinson power divider for a 50Ω system impedance at
frequency F0. The geometry of the circuit is shown in attached figure.
Ploted the return loss (S11), insertion loss (S21 = S31), and isolation (S23 = S32) versus frequency from F1 to F2. The
substrate is selected as FR-4 with an Er = 4.4, height h = 1.6 mm and conductive thickness T
= 35 μm, the dielectric loss tangent is 0.02, and the conductive strip is Copper.

(a) With Ideal TxLine.
(b) With MicrostripTxLine.
(c) Microstrip TxLine with discontinuities.
(d) Tuning of Microstrip TxLine with discontinuities.
